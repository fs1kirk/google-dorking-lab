# Apex Signal Labs - Google Dorking Training Site

This folder is intentionally safe to publish publicly. Every person, email address, project, asset ID, and flag is fictional.

## Free GitHub Pages deployment

1. Create a new PUBLIC GitHub repository, for example `google-dorking-lab`.
2. Upload the CONTENTS of this folder to the repository root.
3. Commit the files.
4. Open Settings -> Pages.
5. Under Build and deployment, select "Deploy from a branch".
6. Select the `main` branch and `/ (root)`, then Save.
7. Open the GitHub Pages URL GitHub provides.

## Indexing

The site includes `robots.txt` allowing crawlers and a crawlable `site-map.html` linking every challenge resource. Search engines may still take days or longer to index a new site.

For more predictable classroom timing, publish well before the workshop and verify each challenge query yourself before class.

IMPORTANT: Do not upload the separate instructor package or its answer key into the public repository.
